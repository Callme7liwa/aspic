# Piscine des Chavannes · Sécurité et autocontrôle (maquette)

Maquette cliquable pour l'ASPIC. Toutes les données sont fictives. Fichier unique, sans dépendance, qui fonctionne hors ligne.

Ouvrir `index.html` dans un navigateur, ou le déployer tel quel (Vercel, site statique).

Écrans :
- `#/` Aujourd'hui : ce qu'il reste à faire avant l'ouverture
- `#/eau` Journal d'autocontrôle de l'eau : saisie, alertes, historique, export Excel
- `#/douches` Légionelles par boiler et dépôt du rapport du laboratoire
- `#/installations` Installations techniques, défauts et lien envoyé à l'entreprise
- `#/equipe` Brevets de sauvetage, défibrillateur, permis de désinfection, exercices
- `#/ronde` Ronde d'ouverture sur téléphone
- `#/rapport` Rapport aux communes, à enregistrer en PDF
- `#/entreprise/D-04` Vue de l'entreprise, sans compte

Les plages et fréquences reprennent les documents d'aide du canton de Vaud (650-FIC-005, 650-DOC-008).
